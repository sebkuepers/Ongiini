## Anchor vocabulary — German first-meeting + everyday phrases

Use this as a reference when generating cards. Not exhaustive; you
know much more German than this list. These are the most-used
building blocks at A1–B1.

| English | German |
|---|---|
| Hello / Hi | Hallo |
| Good morning | Guten Morgen |
| Good afternoon | Guten Tag |
| Good evening | Guten Abend |
| Goodbye | Auf Wiedersehen / Tschüss |
| Thank you | Danke |
| Thank you very much | Vielen Dank |
| Please / You're welcome | Bitte |
| Pleased to meet you | Freut mich, Sie kennenzulernen |
| My name is ... | Ich heiße ... / Mein Name ist ... |
| I am from ... | Ich komme aus ... |
| I have ... years of experience | Ich habe ... Jahre Erfahrung |
| I worked at ... | Ich habe bei ... gearbeitet |
| I am applying for | Ich bewerbe mich für |
| Tell me about yourself | Erzählen Sie mir etwas über sich |
| Why do you want to work here? | Warum möchten Sie hier arbeiten? |
| What are your strengths? | Was sind Ihre Stärken? |
| When can you start? | Wann können Sie anfangen? |
| Do you have any questions? | Haben Sie noch Fragen? |

## Cultural notes for German learners

- The Sie/du distinction is non-trivial — Sie is the formal "you" used
  in workplace + with strangers; du is informal for family, friends,
  children. In interview / business contexts default to Sie. In peer-
  to-peer or casual contexts default to du.
- Capitalisation matters: ALL nouns are capitalised in German. A
  learner writing "haus" instead of "Haus" should be marked partial,
  not wrong — meaning is clear but the form is off.
- Umlauts (ä, ö, ü) and ß are part of the canonical form. "ae" / "oe"
  / "ue" / "ss" are accepted alternatives when umlauts aren't
  available; honour both as correct.
- German word order (V2 in main clauses, verb-final in subordinates)
  surprises learners — for early cards, prefer simple sentences before
  introducing subordinating conjunctions ("dass", "weil").
