How these numbers are made

Every number on this page is computed live from data Ongiini already keeps for the service itself — the per-message usage log, the structural trace log, and the long-term memory store. No raw conversation content leaves the foundation's infrastructure.

The qualitative themes you see under How people use it are not chosen from a fixed list. The local AI model first reads each user message and produces a short description of what the message is about — something like "yellowing maize leaves", "grade 11 chemistry homework", or "VAT registration deadline". Then, periodically, the same model reads the entire collection of those short descriptions with their counts and groups them into named clusters of its own choosing. The clusters above are what the data, not a Berlin committee, suggests as the natural shape of how people use Ongiini.

Professions and roles work the same way: the model reads each user's profile facts and produces a short role descriptor ("smallholder farmer", "matric student", "first-time mother"), then clusters all the descriptors into emergent groups.

Both passes run entirely on the same computer the chat service runs on — no third-party APIs, no data leaving the foundation. Any cluster represented by fewer than five people is folded into "Other" so no single user can be identified.

If you'd rather your data not be counted in any of these statistics — current or future — write to the address in our Privacy Policy with the subject "object to research processing" and your phone number. Your messages stop contributing immediately and retroactively.
